# Phase: P1 — Data ingestion and integrity

Outcome: PASS.

Scope performed:
- Implemented bounded, explicit historical acquisition and local hash-checked
  reuse, preserving original compressed prefixes and complete CSV rows.
- Implemented streaming CSV normalization with source-row provenance, UTC
  microsecond integers and stable timestamp-tie ordering.
- Added attributable invalid-record handling and segment resets for invalid
  states, receipt gaps and file/date boundaries.
- Tested corruption, malformed schema/rows, time units, missing depth, invalid
  numerical values, crossed/locked books, duplicate records and time regressions.

Files changed:
- src/market_microstructure/acquisition.py
- src/market_microstructure/data.py
- tests/test_acquisition.py
- tests/test_data.py
- docs/data-source-evidence.md
- docs/data-dictionary.md
- data/README.md

Dataset/provenance:
- Twelve real 2020 monthly first-day Deribit BTC-PERPETUAL excerpts.
- Individual ignored acquisition manifests and data/raw/manifest.json identify
  canonical URLs, response ranges, source sizes, selection and SHA-256 values.
- Source files, normalized rows and detailed exclusion records remain local.

Tests/checks:

    python -m pytest tests/test_data.py tests/test_acquisition.py -q --tb=short --maxfail=1 --basetemp=.test-tmp-data -p no:cacheprovider

Result: 30 passed. Tests use synthetic transport/source fixtures and do not
download market data. On this Windows host the passing command used the
approved execution path because the default sandboxed pytest temp area was
inaccessible.

Measured results:
- 240,000 input rows; 240,000 retained; zero observed exclusions.
- 54 receipt-time ties preserved in original order.
- Twelve separate file/date segments; zero observed receipt gaps over 30 seconds.
- Observed excerpt duration: 226.571–1,830.118 seconds per date.
- No model performance was measured in this phase.

Acceptance-gate mapping:
- Auditable source -> every state retains file, original row position and
  excerpt-hash provenance key.
- No silent drops -> retained plus excluded equals total, with explicit
  source/row/reason attribution.
- Stable availability -> receipt-time high-watermark check and deterministic
  original order within timestamp ties.
- Boundary safety -> invalid rows/gaps/files/dates reset segments.
- Offline CI compatibility -> synthetic fixtures exercise all source cases.

Limitations / unresolved questions:
- Vendor snapshots may already exclude crossed levels. Zero rejected supplied
  rows must not be described as proof of a clean original exchange feed.
- CSV lacks explicit disconnect markers; gap detection is a heuristic.
- Prefix hashes do not validate whole-day gzip CRC/MD5.
- Size is vendor-native USD notional, not BTC; no raw incremental reconstruction
  is claimed.

Security/permissions/external actions:
- No paid/API-key/live-exchange access. Raw or merely sampled/processed records,
  per-event predictions and fitted models remain excluded from GitHub.

Git status:

- No push is claimed by this handoff; final remote verification is separate.
